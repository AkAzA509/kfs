# How to use it ?
Inside this docs dir you will find all the code related docs to understand his behavior and design.

Each "module" or "part" have is own doc file (all display related code -> diplay.md, all memory related code -> memory.md ...).

```bash
docs
├── display.md
├── memory.md
├── README.md
├── toolchain.md
└── ...
```

The toolchain file details all the required ressources (language, compiler, packages ...)
